Tipos de estilos CSS

Estilos en linea

Estos estilos se van a agregar directamente en el elemento HTML, mediante el atributo "style"

Este parrafo tiene estilo en linea

Estilos internos

Estos estilos se agregan en el mismo archivo html dentro de la etiqueta <head>

Estilos Externos

Estos estulos son los que se recomienda utulizar, ya que ofrecen modularidad, facil entendimiento, orden, eficiencia entre otras ventajas, para agregar una hoja de estilos externa, dentro de la etiqueta <link>
