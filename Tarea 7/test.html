Conceptos principales HTML

HTML

El Lenguaje de Marcado de Hipertexto, es un lenguaje de marcas que se utiliza para estructurar sitios web.

Elemento HTML

Un elemento HTML es la unidad basica de estructura y contenido en una página web y esta compuesta de:

  1. Etiquetas de apertura
  2. Pares atributos-valor
  3. Contenido
  4. Etiqueta de cierre

Etiqueta < Head >

Es una etiqueta que se utiliza para comunicarse con el navegador a tráves de los metadatos, permite mejorar el SEO, además se enlazan archivos externos de estilos o sripts

Etiqueta <Body >

Dentro de esta etiqueta va todo el contenido que ve el usuario en nuestra página web.

Contenedores Semánticos

<header> Es una etiqueta utilizada para el contenido introductorio de una página web, puede contener el logo, el menú principal de navegacion, el nombre de la empresa, etc.
<nav> Etiqueta utilizada para el menú de la navegacion principal, suele contener enlaces a otras páginas relacionadas o navegar por la página principal, no debe de haber más de una en la página.
<main> Etiqueta unica de una página web, cuyo objetivo es resaltar nuestro objetivo o mensaje principal del sitio web, dentro se colocara el contenido principal de nuestra página.
<section> Es una etiqueta que poco a poco se intenta que sustituya a <div>, su uso es para dividir a una página web en secciones y agrupar contenido relacionado.
<article> Es una etiqueta que normalmente se utiliza para agrupar contenido autónomo, que si se separa de otro contenido sigue teniendo coherencia, normalmente se compone de un encabezado y contenido.
<footer> es una etiqueta que normalmente se encuentra al final de una página y funciona como cierre del sitio web, a menudo contiene datos de contacto, derechos de autor, u otra informacion complementaria.
<aside> Esta etiqueta representa una sección de la página web, cuyo contenido no esta relacionado con el contenido principal del documento, como: barras laterales, publicidad, enlaces a otros articulos relacionados, etc.

Elementos principales de HTML

Elemento <a>

Este elemento contiene enlaces para navegar a otras páginas:

  • externos
  • internos
  • anclajes

Algunos valores especiales que tiene en su atributo href son:

href="https://wa.me/5542649521"
Este valor envia un whatsapp a un número en especifico
href="mailto:evelin.blue@icloud.com"
Envia un correo a un e-mail especifico.

Elemento <form>

Es la forma en que los usuarios de un sitio web pueden comunicarse con el mediante el formulario que reciben, procesan y envian datos de los usuarios para el fin u objetivo del sitio web.
